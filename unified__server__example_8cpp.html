Detailed Description

Example showing the new unified server (listener) interface usage.

This file demonstrates the NEW, RECOMMENDED way of creating network servers using the unified interface API.

Benefits:

  • Single interface (i_listener) for all protocols
  • Protocol selection via factory functions
  • Unified callback structure
  • Accepted connections use same i_connection interface
