Detailed Description

Demonstrates connection pooling usage patterns.

This example shows:

  • Basic pool initialization and usage
  • Concurrent connection usage with multiple threads
  • RAII-based automatic connection release
  • Error handling patterns

Build: cmake –build build –target connection_pool_example

Run (requires a running server on localhost:5555): ./build/samples/connection_pool_example
