Detailed Description

Example of using network_system with modern API and Result<T> pattern.

This example demonstrates:

  • Modern network_system API with Result<T> error handling
  • Type-safe error checking with VoidResult return types
  • Integration with thread pool and container systems
  • Proper error handling and recovery patterns

Note: All primary APIs (start_server, start_client, send_packet, etc.) now return Result<T> for type-safe error handling instead of throwing exceptions or using callback-only error reporting.
