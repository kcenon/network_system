# `package/` -- packaging assets for network_system

This top-level directory holds **packaging** assets for distributing
`network_system`. It does not contain library source code and is **not** part
of the compiled build (the root `CMakeLists.txt` does not
`add_subdirectory(package)`); it is used only when producing or testing
distributable packages.

## Contents

- `vcpkg/` -- a local vcpkg overlay port used to test packaging the library
  through vcpkg before publishing. See `package/vcpkg/README.md` for usage.

## Relationship to the build

CMake (with presets) is the single supported build system for this project
(see issue #1153 and #953). The CMake config-file package consumed by
downstream projects via `find_package(network_system)` is generated by the
install rules in `cmake/network_system_install.cmake`, not from this directory.
`package/` is reserved for distribution-channel assets such as the vcpkg
overlay above.
