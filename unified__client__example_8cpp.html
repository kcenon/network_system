Detailed Description

Example showing the new unified client interface usage.

This file demonstrates the NEW, RECOMMENDED way of creating network clients using the unified interface API.

Benefits:

  • Single interface (i_connection) for all protocols
  • Protocol selection via factory functions
  • Cleaner callback setup
  • Protocol-agnostic business logic
See also
legacy_client_example.cpp for comparison with old approach
