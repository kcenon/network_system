QUIC Client Example

This example demonstrates how to use the QUIC client API to connect to a QUIC server and send/receive data.

Note: This sample uses messaging_quic_client directly instead of quic_facade because it needs QUIC-specific features like multi-stream support, 0-RTT, and connection statistics. The quic_facade returns i_protocol_client which provides a unified interface but doesn't expose QUIC-specific methods.

Key features demonstrated:

  • Basic connection and disconnection
  • Sending data on the default stream
  • Creating and using multiple streams (QUIC-specific)
  • Handling callbacks for various events
  • Using configuration options
