Detailed Description

Public header for Result<T> error handling types.

This is the public API header for result types. Use this header instead of including detail/utils/result_types.h directly.

Example usage:

#include <kcenon/network/types/result.h>
auto connect() -> kcenon::network::Result<void> {
// ... connection logic
return kcenon::network::ok();
}
